## Slide 7: What HALO V0 Is Really Testing

Can a pocket-sized drone reliably interrupt a threat—just long enough to escape?

This isn’t about battery life or navigation algorithms.  
It’s about a behavioral response to chaos—light, sound, movement—in real-world tension.

Here’s what we’re testing:  
✅ Flinch rate — Do 90%+ of subjects involuntarily react (blink, pause, recoil)?  
✅ Interruption window — Does the threat pause for at least 2–3 seconds?  
✅ Escape margin — Can users create 5–10 feet of separation?  
✅ Confidence effect — Do users feel safer carrying HALO daily?

If we can cause a moment’s hesitation, we can give someone a chance to escape.  
If we can measure that, we can scale it.
